# Forest visual acceptance checklist

Run `npm run dev`, open the local URL, and verify:

- The waiting screen uses the earthy pixel-panel theme and remains keyboard accessible.
- Four forest layers move at visibly different rates as the leader-following camera advances.
- Terrain collision is unchanged while platforms show grass, dirt, stone details, and dark edge caps.
- Lanterns, signs, benches, rocks, and shrubs decorate the route without blocking players.
- All four runners remain readable and switch between idle, run, jump, and fall poses.
- Checkpoints, ability pickups, the danger edge, rockets, and the finish marker remain easy to identify.
- Pickups collect once, rockets target and hit, and respawn locations remain safe.
- The question, target-selection, and results dialogs remain readable at desktop and mobile widths.
- Reduced-motion mode suppresses interface animation and does not affect gameplay.
- A complete match can be started, played, finished, and restarted without rendering errors.
